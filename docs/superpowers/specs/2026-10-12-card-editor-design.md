# 카드 에디터 설계 (웹)

- 작성일: 2026-10-12
- 대상: 게임 밖에서 카드를 기획·공유하는 웹 도구
- 상태: 승인 대기
- 참고: Notion 「세계관 > 카드」 페이지의 카드 예시 그림

## 1. 배경

카드를 Notion 데이터베이스에 정리하려 했으나 긴 지문을 넣기 불편하고, 카드 모양으로 보이지 않는다. 직접 쓴 내용이 카드 모양으로 보이고 덱처럼 모아 볼 수 있는 도구가 필요하다.

## 2. 확정 사항 (2026-10-12 사용자 결정)

| 항목 | 결정 |
|---|---|
| 용도 | 기획 아이디어 보관, 팀 공유·리뷰, 게임 데이터 원본 (셋 다) |
| 형태 | claude.ai 아티팩트 웹 페이지. Godot 불필요 |
| 문구 | 모두 직접 쓴다. 효과 수치에서 자동으로 만드는 문구는 없다 |
| 카드 모양 | Notion 예시 그림을 따른다 (3장) |
| 키워드 | 넣지 않는다 |

## 3. 카드

### 3.1 입력 항목

| 항목 | 형식 | 필수 |
|---|---|---|
| 이름 | 한 줄 글 | 예 |
| SP | 0 이상 정수 | 예 |
| 분류 | 공격 / 스킬 / 특수 | 예 (기본 공격) |
| 공격 종류 | 근접 / 원거리 / 아군 / 자신 | 예 (기본 근접) |
| 범위 | 5×5 격자에서 칸 선택. 가운데가 기준 칸 | 아니오 (비면 가운데 한 칸) |
| 일러스트 | 이미지 파일 | 아니오 |
| 설명 | 여러 줄 글. 줄바꿈 유지 | 아니오 |

### 3.2 모양

```
┌─────────────────────┐
│        이름         │
│(SP)┌─────────────┐⚔ │  공격 종류 아이콘
│    │   일러스트   │▦ │  범위 미니 격자
│    └─────────────┘   │
│        설명         │
└─────────────────────┘
```

- SP 원은 일러스트 칸 왼쪽 위 모서리에 겹친다
- 테두리 색은 분류로 정한다: 공격 빨강, 스킬 파랑, 특수 보라
- 일러스트가 없으면 빈 칸(옅은 무늬)을 그린다
- 설명이 길면 카드 안에서 글자를 줄이지 않고 잘라 보이며, 편집 창에서는 전부 보인다

## 4. 화면

### 4.1 카드 목록

- 모든 카드를 카드 모양 그리드로 보여준다
- 분류별 필터, 이름·SP 정렬, 이름 검색
- "새 카드" 버튼, 카드를 누르면 편집 창

### 4.2 편집 창

- 왼쪽 입력 칸, 오른쪽 실시간 미리보기
- 저장, 삭제(확인 후), 복제
- 덱에 추가 (덱 고르기)

### 4.3 덱

- 덱 여러 개를 만들고 이름을 바꾸거나 지울 수 있다
- 덱에는 카드와 장수가 들어간다. 장수는 +/- 로 조절, 0이 되면 빠진다
- 덱 화면은 카드를 펼쳐 보이고 장수를 배지로 표시한다
- 위에 총 장수와 SP별 장수 막대를 보여준다
- 장수·코스트 제한 규칙은 넣지 않는다

## 5. 저장과 공유

- 카드·덱은 아티팩트 공유 데이터베이스에 저장한다. 링크로 연 팀원도 같은 데이터를 보고 고칠 수 있다
- 일러스트는 아티팩트 파일 저장소에 올리고 카드에는 그 주소만 둔다
- 카드를 지우면 그 카드가 들어간 덱에서도 빠진다
- 동시에 같은 카드를 고치면 마지막 저장이 이긴다

### 초기 데이터

현재 게임 플레이어 카드 7장(`Resources/cards/*.tres`)의 이름·SP·공격 종류·범위를 넣고 설명은 비워 둔다. 덱은 유닛 `.tres` 의 덱 구성대로 만든다.

## 6. 범위 밖

효과 수치, 키워드, `.tres` 가져오기·내보내기, 덱 규칙 검사, 적 카드, 인쇄용 출력, 변경 기록.
