# 카드 에디터: 덱 전용 카드 설계

- 작성일: 2026-10-12
- 상태: 승인 대기
- 선행 문서: `2026-10-12-card-editor-design.md` (이 문서가 4.3 덱과 5 저장의 덱 부분을 대체한다)

## 1. 배경

지금은 카드를 전체 목록에서 만든 뒤 덱에 넣는다. 덱(캐릭터)마다 카드를 따로 만들고 보는 쪽이 팀의 쓰임에 맞다. 이 도구는 팀이 보기 위한 데이터베이스이므로 장수 관리는 필요 없다.

## 2. 확정 사항 (2026-10-12 사용자 결정)

| 항목 | 결정 |
|---|---|
| 카드 소속 | 덱 카드는 그 덱 전용. 다른 덱과 공유하지 않는다 |
| 공용 카드 | 덱과 별개로 기존 카드 탭에서 따로 관리. 덱에 넣는 기능 없음 |
| 장수 | 없음. 덱에는 카드가 한 장씩 |

## 3. 데이터

- 카드 문서에 `deckId` 를 추가한다. 문자열이면 그 덱 전용 카드, `null` 이면 공용 카드
- 덱 문서는 `{ name, createdAt }` 만 둔다. `entries` 는 쓰지 않는다
- 기존 데이터 이전
  - 각 덱의 `entries` 에 있던 카드마다 그 덱 전용 사본을 만든다. 문서 id 는 `<덱id>--<카드id>`, 장수는 버린다
  - 원래 카드 7장은 공용 카드(`deckId: null`)로 남긴다
  - 덱 문서에서 `entries` 를 지운다
  - `seed.json` 도 같은 모양으로 바꾼다

## 4. 화면

### 4.1 공용 카드 탭

- 탭 이름을 "카드" 에서 "공용 카드" 로 바꾼다
- `deckId` 가 없는 카드만 보여 준다. "새 카드" 는 공용 카드를 만든다

### 4.2 덱 탭

- 왼쪽 덱 목록: 덱 이름과 카드 수
- 오른쪽: 덱 이름(바꾸기), "이 덱에 새 카드", 덱 삭제, 카드 수와 SP별 카드 수 막대, 그 덱 카드 그리드
- 카드를 누르면 편집 창
- 덱 삭제는 두 번 눌러야 하고, 버튼에 "카드 N장도 삭제" 를 표시한다. 그 덱의 카드와, 다른 카드가 쓰지 않는 일러스트도 지운다

### 4.3 편집 창

- 새 카드는 연 곳에 따라 소속이 정해진다 (공용 카드 탭 → 공용, 덱 → 그 덱)
- "덱에 추가" 를 "다른 덱에 복사" 로 바꾼다. 덱 카드와 공용 카드 모두에서 쓸 수 있고, 고른 덱의 전용 카드로 사본을 만든다(일러스트 id 는 공유)
- 복제는 같은 소속 안에 사본을 만든다
- 제목에 소속을 보여 준다 (예: "사수 · 카드 편집", "공용 카드 · 새 카드")

## 5. 범위 밖

장수, 공용 카드를 덱에 넣기, 카드를 다른 덱으로 옮기기(복사 후 삭제로 대신), 공용 카드 탭의 추가 개편.
