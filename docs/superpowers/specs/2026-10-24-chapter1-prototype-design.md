# 튜토리얼 + 1장 프로토타입 설계

- 작성일: 2026-10-24
- 기준 디자인: Figma `Game UI Wireframes` → `v6 · 연보라 사이드 패널` (사무소 사이드 레일, 연보라 패널, 전투 흐름)
- 선행: `2026-10-08-map-party-inventory-design.md` (파티·장비), 전투 규칙 문서들

## 1. 목표

메뉴부터 전투까지 한 번에 플레이할 수 있는 프로토타입: 타이틀 → 메인 메뉴 → 프롤로그·튜토리얼 → 사무소 → 1장 원정(5구역) → 정화 → 에필로그. 분량은 림버스 거울 던전 5층 런 수준(전투 약 12회 + 사건·휴식·보급).

## 2. 흐름 (`Scripts/view/game_root.gd`)

`GameRoot` 가 화면을 하나씩 띄우고 결과를 `await` 로 기다리는 순서대로 진행한다.

1. **새 게임**: `prologue` → 튜토리얼 전투 1(쥐 2, 선배 3명과 함께, 안내 문구) → `tutorial_mid` → 전투 2(잠든 자+쥐, 흐트러짐 안내) → `tutorial_deeper` → 황혼의 손(이길 수 없는 연출 전투, 도망 불가) → `tutorial_escape` (공허 능력 발현, 장로 혈귀, 홍연 합류) → 사무소.
2. **사무소**: 의뢰 게시판(1장 / 반복 의뢰), 사원 명부·창고(PartyView), 일지, 저장하고 메인 메뉴로.
3. **원정**: 구역마다 왼쪽→오른쪽 3줄 노드 지도(열 4개 + 출구). 노드는 이웃 줄로만 이어지고(선 교차 없음) 지금 노드와 이어진 다음 노드만 고를 수 있다. 노드: 전투·정예·사건·휴식·보급·상점(구역마다 1개). 출구는 3구역 정예, 5구역 보스. 3구역 뒤 "공허 속의 공허" 선택(황혼층: 적 ×1.15, 자금 ×1.5).
4. **보스 처치 후**: `ch1_purify` → 신의 힘 3택 1(자금/장비/카드) → `ch1_epilogue` → 1장 완료, 반복 의뢰 해금.
5. **전멸**: 되살아난다(소장 수명 −1년, 체력 회복 후 다시 고르기) / 철수(원정 종료).

## 3. 전투 규칙 추가 (`Scripts/combat/`)

| 규칙 | 내용 |
|---|---|
| 이동력 | `UnitData.move`. 차례마다 그만큼 걸을 수 있다(BFS, 같은 편 칸은 못 지나감). 이동에 SP 를 쓰지 않는다. |
| 흐트러짐 | `UnitData.stagger`. 받은 공격 피해만큼(방어도로 막아도) 깎인다. 0 이 되면 적은 기절·아군은 탈진 → 다음 차례를 쉬고 게이지가 다시 찬다. 전투가 끝나면 사라진다. |
| 상태 스택 | `Unit.statuses`. 현재는 혈갑(최대 10). |
| 혈갑 (홍연 패시브) | 차례 시작 시 혈갑 스택만큼 방어도. |
| 피의 갈망 (홍연 패시브) | 체력을 잃을 때마다 혈갑 +1, 적 처치 시 +2. |
| 카드 효과 | `GAIN_STATUS`(상태 획득), `BURST`(스택 전부 소모, 스택당 공격 % 피해), `HP_COST`(체력 소모, 1 은 남김), `STAGGER`(흐트러짐만) |
| 시작 체력 | `UnitPlacement.start_hp` — 원정 체력이 전투로 이어진다. |

## 4. 데이터

- `tools/generate_content.gd` 가 표로 정의한 카드 39장, 아군 5명(한결·홍연·튜토리얼 선배 3명), 적 7종(공허 쥐·잠식된 들개·공허 거머리·잠든 자·검은 기름 거인·하수도의 왕관·황혼의 손), 전투방 4종을 `Resources/content/` 에 `.tres` 로 저장한다. 이후에는 에디터에서 직접 고쳐도 된다(다시 실행하면 표 값으로 덮어씀).
- 의뢰 정의(층·적 무리·정예·보스·사건·보상 카드 풀)는 `Scripts/game/chapter_data.gd`.
- 대본은 `Resources/story/*.txt` 의 줄 단위 형식(`StoryScript` 주석 참고). 사건 6종은 `Resources/story/events/`.
