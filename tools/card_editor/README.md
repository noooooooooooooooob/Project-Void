# 카드 에디터

카드의 이름·SP·지문을 직접 쓰면 카드 모양으로 보여 주고, 덱(캐릭터)별로 모아 볼 수 있는 웹 도구입니다. claude.ai 아티팩트로 게시되어 있습니다.

**링크:** https://claude.ai/artifact/T2zETQHPfWew1HejtgHKHd

- claude.ai 계정으로 로그인해야 열 수 있습니다.
- 공유받은 사람만 볼 수 있습니다.
- 게임(Godot) 데이터와는 따로 저장됩니다. 여기서 고친 카드는 게임에 자동으로 반영되지 않습니다.

## 사용법

카드는 두 종류입니다.

- **덱 카드**: 한 덱(캐릭터) 전용 카드입니다. 덱 탭에서 만들고 봅니다.
- **공용 카드**: 덱에 속하지 않는 카드입니다. 공용 카드 탭에서 따로 관리합니다.

### 카드 만들기

1. 덱 카드는 **덱** 탭에서 덱을 고르고 **이 덱에 새 카드**를 누릅니다. 공용 카드는 **공용 카드** 탭 오른쪽 위 **새 카드**를 누릅니다.
2. 편집 창에 내용을 채웁니다. 입력하는 대로 오른쪽 미리보기에 바로 보입니다.

   | 항목 | 설명 |
   |---|---|
   | 이름 | 카드 이름 |
   | SP | 0 이상 정수 |
   | 분류 | 공격(빨강) · 스킬(파랑) · 특수(보라). 카드 테두리 색이 바뀝니다 |
   | 공격 종류 | 근접 · 원거리 · 아군 · 자신. 카드 오른쪽 위에 근·원·아·자 배지로 표시됩니다 |
   | 범위 | 5×5 칸을 눌러 켜고 끕니다. 가운데 칸이 기준 칸이고, 아무것도 고르지 않으면 단일입니다. 좌표는 게임 `CardData.area`와 같습니다 (오른쪽이 뒤쪽, 아래가 +) |
   | 일러스트 | PNG · JPG · WEBP · GIF, 20MB 이하. 선택 사항입니다 |
   | 설명 | 지문을 자유롭게 씁니다. 줄바꿈이 그대로 보이고, 최대 2만 자까지 쓸 수 있습니다 |

3. **저장**을 누릅니다.

### 카드 고치기

- 목록에서 카드를 누르면 편집 창이 열립니다. 고친 뒤 **저장**을 누릅니다.
- 편집 창 제목에 어느 덱 카드인지 표시됩니다 (예: "사수 · 카드 편집").
- **복제**를 누르면 같은 덱에 "○○ 사본"이 열립니다. 저장해야 실제로 만들어집니다.
- **다른 덱에 복사**로 고른 덱에 같은 카드를 한 장 만듭니다. 이후에는 서로 따로 고칩니다. 카드를 다른 덱으로 옮기려면 복사한 뒤 원래 카드를 지웁니다.
- **삭제**는 두 번 눌러야 지워집니다.
- 공용 카드 탭에서는 칩으로 분류별로 걸러 볼 수 있고, 이름 검색과 이름순·SP순 정렬도 됩니다.
- 카드 안에서는 긴 이름과 설명이 잘려 보이고, 편집 창에서는 전부 보입니다.

### 덱 만들기

1. 위쪽 **덱** 탭으로 갑니다. 처음에는 사수 · 정찰병 · 선봉 덱이 게임 구성대로 들어 있습니다 (카드 종류마다 한 장씩).
2. **새 덱**을 누르고, 위쪽 이름 칸을 눌러 이름을 바꿉니다.
3. **이 덱에 새 카드**로 카드를 만듭니다.
4. 위쪽에 카드 수와 SP별 카드 수 막대가 보입니다.
5. **덱 삭제**는 두 번 눌러야 지워지고, 그 덱의 카드도 함께 지워집니다. 버튼에 지워질 카드 수가 표시됩니다.

### 팀원과 같이 쓰기

- 페이지 오른쪽 위 **공유** 메뉴에서 팀원을 추가합니다.
- 권한
  - **Contributor 이상**: 카드와 덱을 만들고 고칠 수 있습니다.
  - **Viewer**: 보기만 할 수 있습니다. 화면에 "읽기 전용으로 보고 있어요"가 표시됩니다.
- 그림 업로드 기능이 있어서 공개 링크로는 공유할 수 없습니다. 조직 안이나 초대한 사람만 볼 수 있습니다.
- 누가 고치든 모두의 화면에 바로 반영됩니다. 같은 카드를 동시에 고치면 마지막에 저장한 내용이 남습니다.

## 알려진 제한

- 그림을 바꾸거나, 올리고 저장하지 않으면 이전 그림 파일이 저장 공간에 남습니다.
- 다른 사람이 지운 카드를 편집 창에 열어 둔 채 저장하면 카드가 다시 생깁니다.
- SP에 아주 큰 숫자를 넣으면 카드의 SP 원 밖으로 넘칩니다.
- 덱 이름이 아주 길면 덱 목록 밖으로 넘칩니다.
- 장수, 공용 카드를 덱에 넣기, 효과 수치, 키워드, 게임 `.tres` 가져오기·내보내기는 없습니다.

## 개발

이 폴더는 `.gdignore`로 Godot 가져오기에서 빠져 있습니다.

| 파일 | 역할 |
|---|---|
| `card_model.js` | 순수 로직: 검증, 범위, 필터·정렬, 덱 카드 계산, 데이터 이전 |
| `index.src.html` | 화면 (스타일과 앱 스크립트) |
| `build.mjs` | `card_model.js`를 HTML에 인라인해서 `dist/card-editor.html`을 만듭니다 |
| `seed.json` | 초기 공용 카드 7장, 덱 3개, 덱 카드 12장 |
| `*.test.js` | Node 내장 테스트 |

```bash
# 저장소 루트에서
node --test "tools/card_editor/*.test.js"   # 테스트
node tools/card_editor/build.mjs             # dist/card-editor.html 생성
```

`dist/card-editor.html`을 위 링크의 아티팩트로 다시 게시하면 반영됩니다. 데이터는 아티팩트 저장소에 있어서 다시 게시해도 지워지지 않습니다.

- 카드: `cards/{id}` 컬렉션. `deckId` 가 덱 id 면 덱 카드, `null` 이면 공용 카드
- 덱: `decks/{id}` 컬렉션 (`{ name, createdAt }`)

설계 문서: `docs/superpowers/specs/2026-10-12-card-editor-design.md`, `docs/superpowers/specs/2026-10-12-card-editor-deck-cards-design.md`
